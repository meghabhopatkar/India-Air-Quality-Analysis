# India-Air-Quality-Analysis
India Air Quality Analysis using Python, SQL, and Power BI. Performed data cleaning, exploratory data analysis, pollutant comparison, and interactive dashboard development to identify pollution hotspots across Indian cities and states.
India Air Quality Analysis
Project Overview
This project analyzes air quality data collected from various cities and states across India. The goal is to identify pollution hotspots, compare pollutant concentrations, and generate actionable environmental insights using Python, SQL, and Power BI.
